# Close the focused macOS Session with Command-W

Implements [Tauride #127](https://github.com/xpqz/tauride/issues/127).

In macOS Tauride, the existing configurable Close window command closes its
Session when the Session pane has text focus. It uses the normal window-close
path: confirmation can cancel the close; accepting ends a spawned interpreter
or disconnects an external interpreter. Other sessions remain open. Editors and
tracers retain their existing Close behaviour.

The effective Close shortcut is excluded from busy Session typeahead so a
cancelled close cannot replay when the prompt returns. Removed and old shortcuts,
ordinary input and programmable function keys retain normal typeahead behaviour.
Electron and other platforms retain their Session behaviour.

## Validation

Tests were added and independently reviewed before implementation. Four unit
regressions failed against the baseline: focused Session close, customization,
normal confirmation/shutdown and busy Close replay. Twelve existing keyboard
unit tests passed. Both native regressions failed at their Session close checks;
their existing editor and tracer close controls passed.

Post-change validation:

- All 248 JavaScript unit tests pass, including the four new regressions.
- The focused keyboard unit suite passes all 16 cases.
- All 16 targeted native cases pass: Session Close (2), Mac shortcuts (4), input
  state (2), Session (4) and editor (4).
- Native Command-W and the rebound Close shortcut close only the focused
  Session; the surviving Session executes APL. Find input, removal, rebinding,
  reset, editor/tracer close and disconnected Session close are covered.
- A separate native check closed the first session with Command-W, then
  evaluated `2+2` in its surviving sibling; the rendered window was visually
  checked.
- Unit tests run the production before-unload and shim close handlers to verify
  confirmation cancellation/acceptance and spawned Exit versus external
  Disconnect. These use stubbed dialog answers, not physical dialog input.
- Unit guards retain Electron and non-macOS Session behaviour and normal
  typeahead input.
- Independent tests-only and implementation reviews approved the changes.
