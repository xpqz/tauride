# Boxing and Rows menus

Implements [Tauride #123](https://github.com/xpqz/tauride/issues/123). This PR builds on #120 to reuse its Session draft preservation.

View > Boxing exposes Off, No Borders, Minimal, Medium and Maximum. View > Rows exposes Off, Extend, Cut and Wrap, with folding choices for off or zero through nine trailing rows. Each submenu includes Current Settings and Help. The actions send documented `]box` and `]rows` commands to the owning interpreter. Style and folding choices explicitly enable their formatter while preserving unrelated options. Wrap ignores folding, as Dyalog documents.

The interpreter remains the source of truth. As agreed for this version, the menus use plain actions plus Current Settings, which queries the interpreter; Tauride keeps no parallel settings or speculative checkmarks. The new command codes work in the existing menu and shortcut preferences, with no default shortcuts. Saved custom menus remain unchanged. The user guide lists the codes and explains advanced options and interpreter-session persistence.

Execution requires a connected, idle interpreter at its normal prompt with no pending input operation. Unfinished input, modified history and selections survive the echoed command, output and return to the prompt. Floating panes delegate to their owning session, and native menu actions follow the focused session; helper windows cannot change a background interpreter.

Native roles follow explicit clipboard command codes (`CT`, `CP`, `PT`), so Rows > Cut retains its interpreter action even though its label matches a clipboard item. Session draft restoration also retains a clean empty prompt before restoring its caret or history selection, including when command output arrives in partial chunks.

## Validation

The new unit and live tests were written first and independently reviewed. Regressions demonstrated the missing Boxing action, native Rows > Cut being mistaken for clipboard Cut, and an empty prompt losing its six-space indentation and caret position. Independent implementation review approved the menu, dispatch and prompt corrections.

- All 219 Node tests pass; all three Rust menu tests pass.
- Browser build and smoke test pass with no missing resources or console errors.
- All seven output-menu live tests pass on each of Dyalog 19, 20 and 21, covering every setting, visible output, drafts and selections, normal and input prompts, native routing and floating windows.
- Actual macOS menu checks pass for Rows > Cut and Boxing > Maximum, including prompt indentation. After entering `]rows on -style=wrap` directly, Rows > Current Settings reports Wrap.
- Thirty related live checks pass on Dyalog 21: inline tracing, native session and helper routing, input state, Session entry, clearing visible history, editor clipboard/shortcuts and Preferences selection.

The live clean-history selection fixture was corrected to find the echoed expression's actual column instead of assuming indentation. Earlier test-app launches also encountered intermittent WebDriver startup timeouts before test bodies ran; affected tests were rerun without increasing timeouts.
