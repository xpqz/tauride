# #39: Align Comments preserves unselected standalone comments

With an empty selection, Align Comments previously padded every comment delimiter in the function. Standalone comment indentation could move, and a deeply indented standalone comment could push inline comments farther right.

`AC` now retains whether the selection was empty. During whole-function alignment, comment-only lines are excluded from both the maximum alignment column and the edits. Standalone detection checks the original text before the real comment delimiter, so a quoted string followed by a comment still counts as code. Existing string scrubbing locates the delimiter; explicit selections retain their existing behavior, including the partial-selection guard from #4.
