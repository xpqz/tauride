# #38: Edit at column 1 of a tracer

Edit at column 1 of an unindented tracer sent position zero, which selected the first name and opened another editor. `ED` now sends the existing beyond-line conversion position when the caret is at column 1 in a tracer. The request retains the original window token. Regular editors and name positions elsewhere in tracers continue to use the caret's Unicode position.

The change reuses the empty-space conversion request rather than adding a new protocol operation. Empty-space actions, indented lines, and empty tracer lines use the same path.
