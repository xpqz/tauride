# #41: Insert a soft tab on the first empty shell-completion reply

The first manual Tab in shell completion mode returned from prefix handling even when the interpreter supplied no matches. It inserted no whitespace and left the manual completion count at one. Classic mode and a second shell Tab already reached the empty-reply fallback.

`src/ac.js` now enters shell prefix handling only when options exist. An empty reply reaches the existing fallback, which cancels suggestions, clears manual completion state, and inserts whitespace to the next indentation stop for a manual request. Automatic replies still insert nothing.

`tests-node/labels-completion.js` calls the actual `D.ac` callback, covering shell and classic empty replies at several caret columns and indentation widths, including the default width when the preference is zero. Controls cover automatic empty replies, second Tab, one and several matches, common-prefix insertion, unchanged-prefix second-Tab suggestions, classic suggestions, and automatic shell replies with matches. The direct below-threshold indentation control invokes the actual `D.Ed.indentOrComplete` command.

Tests were written and reviewed before implementation. The combined #40/#41 baseline had 15 failing tests and 16 passing controls; five failures checked the first empty shell reply. After the two minimal fixes, `node --test tests-node/labels-completion.js tests-node/language.js` passes all 40 tests. `git diff --check` passes for the changed source and regression file. Source ESLint reports the same existing diagnostics as the saved worktree baseline, with none added by this change.

The actual `D.ac` callback with real Monaco in the native Tauri webview inserts one space at column 8 on both first and second manual empty replies in shell and classic modes. Automatic empty replies leave the text unchanged, and all six cases leave the pending completion count at zero. Native results are recorded in `/private/tmp/tauride-36-41-native-results.json`. The screen was locked; physical Tab delivery was not verified. The full 99-test unit suite, `test:build`, and browser zf smoke check pass.
