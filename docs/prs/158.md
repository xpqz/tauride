# Show error explanation panel buttons only when they apply

Implements [Tauride #158](https://github.com/xpqz/tauride/issues/158). Branch `claude/158-panel-buttons`.

The panel's controller derives the buttons that apply from its state (`actions`), and the panel shows only those:

| Button | Shown |
|---|---|
| Enable Observation | observation is off |
| Check Again | setup failed (missing, signed out, unavailable) |
| Cancel | an explanation is running |
| Try Again (was Explain error) | the last explanation was cancelled or failed |
| Copy error context | an error context has been captured |
| Close | always |

**Open Preferences** is removed; the user documentation names Preferences > Code > Code Agent. A successful **Check Again** continues with the explanation that was asked for (ruled in review), where it previously stopped at "ready".
