# Whole Select folding

Implement [Tauride #103](https://github.com/xpqz/tauride/issues/103), following the request for both whole-block and branch folding in [Dyalog/ride #1275](https://github.com/Dyalog/ride/issues/1275).

A `:Select` now has an outer fold through its closing `:EndSelect` or generic `:End`, while `:Case`, `:CaseList`, and `:Else` retain independent folds. Folding the outer block leaves its `:Select` line visible. Reopening it preserves collapsed child folds; Fold All and Unfold All use the same hierarchy. The existing folding preference controls the feature in both editors and tracers.

Branch folds end before the next branch header; the final branch includes the closing line as before. Comments between `:Select` and its first case belong to the outer fold, without a second shorter fold competing at the same line. Incomplete blocks extend to the end of the file, and empty single-line ranges are omitted. A final empty case header stays visible.

For multiple control statements on one line, the outermost fold owns the shared start. If a nested closer shares a line with the next enclosing branch header, the preceding folds all end before that line, keeping the new header visible and the ranges properly nested. The same rules normalize equivalent same-line If/Trap constructs; ordinary If/Trap branch boundaries are preserved.

The tokenizer retains a stable Select identity alongside the existing changing branch identity. The folding provider derives its hierarchy from those token states, without a second source parser or changes to indentation rules. Existing tracer highlighting reveals the folded ancestors of the current execution line.

## Validation

- Tests were added before implementation and failed for missing outer Select ranges; later boundary regressions demonstrated crossing ranges and a hidden final empty case before their fixes.
- All 117 Node tests pass, including 20 language tests.
- Both new Tauri tests pass in actual editor and tracer modes: exact nested ranges, independent collapse, retained child state, Fold All/Unfold All, and highlight-driven reveal of every folded ancestor.
- The zero-footprint bundle builds and its headless Chrome smoke test passes, checking real Monaco whole/branch ranges and retained child state with a preamble comment.
- The Tauri test build and diff checks pass. Independent review approved the final code and tests. ESLint reports the same seven pre-existing findings in `src/mon_apl.js` as the base revision, with none added by this change.
