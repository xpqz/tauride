# Customizable macOS keyboard defaults

Implements [Tauride #121](https://github.com/xpqz/tauride/issues/121).

macOS gets Command-S for Fix, Control-C for Strong Interrupt, Command-F for Find,
Command-Option-F for Replace, Command-Shift-P for the editor command palette,
Command-/ for Toggle Comment and Shift-Option-F for Reformat. Keypad Divide and
existing Command-W/Command-comma bindings remain available. The existing command
registry, shortcut preferences and menu DSL provide customization.

Explicit custom bindings and empty bindings take precedence over defaults.
Live changes remove stale and inherited shortcuts for the managed Mac commands.
Native menus and editor key bindings follow the same effective assignments and
act on the focused eligible pane, including floating editors and busy sessions.
Saved custom menus are retained.

Weak Interrupt has no default shortcut on macOS. The inherited Control-Pause/Break
accelerator displays a missing glyph in native macOS menus. The Action menu
command and explicitly saved WI mappings remain available; Windows and Linux
retain Control-Pause/Break.

Windows/Linux defaults, APL glyph entry, programmable function keys and execution
and tracing keys are unchanged. Broader mapping decisions remain open under
#47 and #102; they need physical testing with users of those platforms.

## Validation

The live regression fails against the previous native build because Command-S
does not send SaveChanges. Node tests also expose missing defaults, custom-binding
collisions, stale registrations and missing native focus guards before the fix.
Native checks additionally reproduced Strong Interrupt being replayed from the
busy Session type-ahead buffer. The mapped interrupt is excluded from that
buffer while ordinary input is retained.

Validation on macOS with Dyalog 21.0.54424:

- 185 JavaScript unit tests pass.
- All 54 native UI tests have passing results. The full run passed 52; after
  correcting interpreter setup synchronization and the old menu-owner assertion,
  all 12 tests in the two affected files passed on rerun.
- Five Rust tests pass, including focused menu ownership, helper accelerator
  exclusion and physical punctuation input in the native test driver.
- The zero-footprint distribution builds and passes its browser smoke test.
- A separate native inspection confirms all seven menu commands are present and
  the Shortcuts page displays Command-S for Fix.
- Independent implementation and final regression reviews approved the changes.

The platform acceptance process is: inspect the effective mapping in Shortcuts
and menus; exercise real keystrokes in Session, editor and tracer panes; rebind,
remove and reset through Preferences; repeat with floating panes, multiple
sessions, helpers and the user's APL input method. Windows and Linux adoption is
deferred until that process can be run physically with users.

## Integration validation

Integrated with Inline Tracing ([#120](https://github.com/xpqz/tauride/pull/120))
and Boxing/Rows ([#124](https://github.com/xpqz/tauride/pull/124)). Native menu
routing retains all three command sets. Helper windows release accelerators for
editing, interrupt, inline tracing and output commands, including custom
assignments; diagnostic Find and clipboard actions remain available. The owning
session installs the focused window's menu, then the focused window refreshes
inline and output availability.

Combined validation on macOS with Dyalog 21.0.54424:

- All 238 JavaScript unit tests and all eight Rust tests pass.
- All 29 native UI tests have passing results. The combined run passed 28; its
  remaining failure came from opening About without first giving its session
  native focus. After correcting that setup, all five inline tests passed on
  rerun, retaining the menu-owner and disabled-state assertions.
- Preferences records the existing inline tracing shortcut without a native
  accelerator intercepting it. Independent review approved the integration and
  final test correction.
